# Fortune Cookie for the Liquidated Trader

This is my entry for the make.fun bounty "Fortune Cookie for the Liquidated Trader". It is a one-line fortune cookie message for a trader who just got liquidated: a small, wry reminder that losing money is not the same as losing your luck.

Run `python3 main.py` and it writes the fortune to `/output/entry.txt`.

## How it works

The program holds a single fortune string and writes it, exactly as written, to `/output/entry.txt`, creating the output folder first if it does not exist yet. It uses only the Python standard library, needs no network access, and always produces the same one-line result: 91 characters, well inside the competition's 160-character limit.
